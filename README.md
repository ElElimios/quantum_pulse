# QuantumPulse Study

Plataforma educativa limpia y moderna de problemas dinámicos de matemáticas y física para estudiantes de preparatoria y nivel universitario.

## Características

- **Generación dinámica de problemas:** Las variables de los ejercicios se generan algorítmicamente en cada carga de tema, garantizando práctica ilimitada.
- **Múltiple opción:** Cada problema cuenta con 4 opciones de respuesta limpia estructurada.
- **Sin distracciones:** Diseño minimalista libre de emojis y listas con viñetas para fomentar la concentración técnica.
- **Soporte bilingüe:** Español e inglés con alternador instantáneo.
- **Modo oscuro y claro:** Tema adaptable con transiciones cómodas.

## Estructura del Proyecto

Esta es la estructura del proyecto recomendada para abrirlo en Visual Studio Code:

```text
quantum_pulseapp/
├── index.html       # Estructura e interfaz principal de la plataforma
├── style.css        # Estilos visuales limpios y variables de tema (claro/oscuro)
├── app.js           # Base de datos de temas y lógica de generación de ejercicios
└── README.md        # Documentación general y guía de despliegue
```

## Guía de Despliegue en Vercel

1. Sube este directorio (`quantum_pulseapp`) a tu repositorio de GitHub.
2. Inicia sesión en [Vercel](https://vercel.com/).
3. Haz clic en **Add New** > **Project**.
4. Importa tu repositorio de GitHub `quantum_pulseapp`.
5. Vercel detectará de manera automática que es un proyecto de frontend estático.
6. Haz clic en **Deploy** y tu página estará lista en menos de un minuto.

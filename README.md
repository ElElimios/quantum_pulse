Math and Physics Project

Quantum pulse is a project made to learn about maths and phyisics, its not that detailed, just basic explanations but you can easily learn of just test if you know these topics. I hope you like it.
---

## Website Features

- Option to switch languages between Spanish and English.
- Toggle button for light mode and dark mode.
- 5-question quizzes for each topic with randomized questions and values.
- Instant feedback showing whether your answer is correct or incorrect.

---

## Project Files

- index.html: Contains the main HTML structure of the website.
- styles.css: Contains all the colors, styling, and visual layout.
- script.js: Contains the JavaScript code with topic data, question pools, and interactive logic.

---

## How It Works

- When you enter, select a subject (Math or Physics).
- Choose the topic you want to review.
- Read the lesson and complete the 5-question test at the bottom.
- Clicking the reset button generates a new set of questions so you can keep practicing.
